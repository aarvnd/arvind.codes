# arvind.codes

Personal portfolio and blog of Arvind, full-stack developer and automation engineer.

- Next.js 16 (App Router), React 19, Tailwind CSS v4, MDX
- Content lives in `src/features/portfolio/data/` (profile, projects, experience, tech stack, timeline) and `src/features/doc/content/blog/` (posts)
- Deployed as a Node.js web app on Hostinger (`next build --webpack`, standalone output)

## Development

```bash
pnpm install
pnpm dev
pnpm build
pnpm start
```
